## 5. Flake found and hardened — `tests/integration/dsh-failures.test.mjs` (OBSERVED)

**Finding.** The exact baseline command (default `--test` concurrency)
initially **did not complete** on this host. `tests/integration/dsh-failures.test.mjs`
has two tests that spawn the DSH ACP fixture and asserted after a fixed
`setTimeout(…, 30)`:

- `dsh malformed and unsupported requests fail closed`
- `cancel is an explicit bounded protocol operation`

Under the CPU contention of the parallel run (several files driving `cargo`
simultaneously), the fixture's first frame had not arrived within 30 ms, so the
assertion threw **before** `child.kill('SIGTERM')`; the two fixture children were
orphaned and kept the test process alive, hanging the whole run. It reproduced on
two consecutive full parallel runs at the same two tests (38 ms / 32 ms) without
reaching any product assertion. Isolation re-run passed (8/8), confirming a
load-dependent harness fragility — not a product defect and not Linux-specific.

**Hardening (bounded, coordinator-ruled; test file only, no product code).**
`tests/integration/dsh-failures.test.mjs` now uses a local bounded
`waitForFrame(frames, predicate, { timeoutMs: 5000, intervalMs: 10 })` instead
of the fixed sleeps, and both spawned fixtures are killed in a `finally`
(closing the readline interface first), so an assertion failure can no longer
orphan a child or hang the run.

**Re-verification (OBSERVED, after hardening).**

- `node --test tests/integration/dsh-failures.test.mjs` (default parallelism)
  twice → **8 pass, 0 fail**, EXIT 0 both runs; no orphaned `fake-server`
  process after either run.
- Full baseline command, default parallelism → EXIT 0; **390 tests, 347 pass,
  0 fail, 43 skip**, 74.8 s; no hang, no orphan. A `--test-concurrency=1`
  discriminating run gives the identical 347/0/43.

No other pre-existing flake surfaced in the parallel rerun.

## 6. Known boundaries (honest, carried)

- **detached process model (D-S06)** — not ported to Linux: `auto` degrades to
  `attached` with one diagnostic, an explicit `detached` on the incapable host
  fails startup loudly. `crates/external-daemon/src/main.rs`
  `resolve_runtime_process_model`.
- **linux-arm64 excluded** (D-S03) — only `darwin-arm64` + `linux-x64` payloads.
- **dsh / agy runtime absent on the verification host** — probes fail closed;
  no spawn smoke claimed (upstream runtime install is out of scope).
- **zcode runtime form is a single OBSERVED shape** — `<home>/.zcode/server/
  agents/glm/zcode.cjs` (ZCode 0.16.9, attached-remote); other Linux
  distributions are unobserved.
- **Live upgrade drain/activation oracle is macOS-only** — `drain-live` and the
  live `reconcile`/`host-sync-partial` activation tests are `darwin-arm64`
  gated; on Linux only the seam-parametrized drain/identity/recovery subset ran.
- **macOS zero-regression gate open** — needs a mac runner for the full suite
  and the Apple-Silicon `npm pack` gate.
- **CI not executed** — `.github/workflows/npm-publish.yml` (build-linux → merge
  → publish) is structurally asserted and reproduced locally, but no real
  workflow run occurred.
- **umask normalisation boundary** — the payload verifier strictly requires
  mode `755`; `normalizePayloadMode` repairs any non-`755` mode on the
  manifest-named regular files (so a permissive `0002`/`0077`/`0775`
  extraction alike) before the strict read, and the strict verifier itself is
  not relaxed. The repair covers only the manifest-named binaries (not the
  manifest or directories), is skipped for symlinks/absent files, and an
  unrepairable file (e.g. an unwritable target) still fails closed. S06's live
  evidence exercised `0002` and `0775`; the `0077` case is covered by the same
  code path but was not separately live-run.
- **`tools/probes` has no `affected` mapping** — `scripts/test/affected.mjs`
  selects no node block for paths under `tools/` (e.g.
  `tools/probes/codex-app-server/probe.mjs`), so probe changes are not
  auto-selected by `npm run test:affected`.
- **real-home boundaries** — no `~/.codex` / real `~/.zcode/cli/config.json`
  writes; host bindings were verified against controlled homes (S05).
